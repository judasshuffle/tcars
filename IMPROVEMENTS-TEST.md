# Experimental TCARS test

Run `improvements-test/launch-tcars.js` from Running Scripts. The original launcher remains an alternative.

In Session, Place TCARS control creates one movable, session-owned control. Clicking it opens the personal tablet only while this client script is running. Quitting removes it; a persistent domain-wide control cannot independently open each user's tablet without client-side code.

The five adjusted cars, Shoe stability, and all four new models use provisional settings requiring in-world verification. New models are loaded directly from the supplied asset repository; their textures and orientation have not been verified. Selection lists are inline to avoid native popup positioning. Space Track omits its spaceship at load time.
